# Introduction to Taxes and Interest Rates

A financial literacy web application built for HACK.COMS '25.
Teaches students how tax calculations and interest rates work
through interactive lessons and quiz questions.

## Built With
- Python (Flask)
- HTML / CSS / JavaScript

## Features
- Informational pages on tax brackets and interest rate concepts
- Interactive quiz questions to test understanding
- Multi-page navigation with a win/completion screen

## How to Run
1. Install Flask: `pip install flask`
2. Run the app: `python int.py`
3. Open `http://localhost:5000` in your browser
